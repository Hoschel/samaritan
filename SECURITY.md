# Samaritan security policy

## Responsible use

Samaritan provides open-source intelligence, public-source monitoring and
passive network-inspection features. Use it lawfully and only for defensive,
educational or otherwise authorised purposes.

- Do not use the RECON tools against systems you do not own or have permission
  to assess.
- Follow the laws and provider terms that apply to your location and use.
- Treat public-source reports, IP geolocation and CVE keyword matches as
  leads requiring independent verification.
- Do not treat a missing public host-index record as proof that a host is safe.

## Reporting a vulnerability

This repository may be deployed independently by different operators. If you
are running a Samaritan instance, report deployment-specific issues to its
operator. For source-code issues, use the private reporting channel of the
repository where you obtained this copy. Avoid publishing exploitable details
until a fix or mitigation is available.
